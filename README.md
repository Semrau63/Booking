# Booking AI Suite (Blismo-style)

A high-tech booking web app starter with:
- Online booking
- AI phone call and text workflows (free simulation mode)
- Per-account website customization
- Smart rebooking date suggestions
- Google review booster messages
- Fast settings and feature toggles

## Run

```bash
npm start
```

Open `http://localhost:3000`.

## Notes

This repository uses a **free simulation mode** for calls and texts (`FREE-MODE-SIMULATION`).
To go production, connect telephony/SMS providers and LLM APIs in `server.js`.
