# James Walters Grooming — Online Booking Prototype

This repository contains a brand-new lightweight booking app prototype for **James Walters Grooming**.

## What it includes

- Client booking flow with:
  - service selection
  - barber selection
  - date/time selection
  - contact details
- Membership pricing toggle
- Deposit capture simulation
- Waitlist signup
- Dashboard metrics for daily operations
- Automated reminder message simulation (SMS + email text shown after booking)

## Why this is useful

This is a starting point to replicate and extend experiences typically found in tools like Blismo and Square:

- calendar-style appointment management
- payment/deposit handling
- customer contact capture
- operational dashboard visibility

## Run locally

Because this is a static app, you can open `index.html` directly in a browser.

Optional local server:

```bash
python3 -m http.server 4173
```

Then open `http://localhost:4173`.
